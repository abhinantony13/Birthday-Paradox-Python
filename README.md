
# 🎂 Birthday Paradox – Python Project

## About the Project
The Birthday Paradox demonstrates the surprising probability that two people in a group share the same birthday.

This project uses Python to generate random birthdays and perform 100,000 simulations to calculate the probability of matching birthdays.

## Technologies Used
- Python
- VS Code
- Random Module
- Datetime Module

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run the following command:

```bash
py birthdayparadox.py
```

5. Enter the number of people (e.g., 23).
6. Press Enter to start the simulation.

## Sample Result
For a group of 23 people, the probability of matching birthdays is approximately **50.7%**.
